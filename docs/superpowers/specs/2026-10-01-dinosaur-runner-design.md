# 恐龙跑酷游戏 — 设计文档

日期：2026-10-01
状态：已确认（待实现）

## 1. 概述

一款运行在网页浏览器中的极简恐龙跑酷游戏：玩家控制一只恐龙在无限卷轴的世界中奔跑，跳过地面障碍、下蹲躲开空中障碍，分数随存活时间累加，速度逐渐加快直到碰撞死亡。美术采用复古霓虹风格（深色底 + 发光描边）。

## 2. 目标与范围

### 目标
- 一个打开即玩、零依赖、可轻松分享的网页小游戏
- 核心体验：跑、跳、下蹲、躲障碍、破纪录

### 范围内（本次实现）
- 无限跑酷：恐龙自动奔跑，玩家控制跳/蹲
- 两类障碍物：地面仙人掌（跳）、空中翼龙（蹲/躲）
- 计分 + 最高分（localStorage 持久化）
- 难度递增：速度上升、障碍物间隔缩短
- 死亡与一键重开
- 复古霓虹视觉

### 范围外（YAGNI，明确不做）
- 音效 / 背景音乐
- 道具、技能（加速、双跳、护盾等）
- 关卡、Boss、成就系统
- 移动端触屏操作（本次仅键盘）
- 多语言、社交分享、排行榜服务端

## 3. 关键决策

| 维度 | 决定 |
|------|------|
| 平台 | 网页浏览器 |
| 玩法范围 | 极简版（跑 + 跳 + 下蹲，无限跑酷，计分） |
| 美术风格 | 复古霓虹 Retro Neon（深蓝黑底 + 发光描边，青色恐龙 / 品红障碍物） |
| 操作 | 键盘：空格/↑ 跳，↓ 下蹲 |
| 声音 | 暂无 |

## 4. 架构与文件结构

```
test/
├── index.html     # 页面骨架：<canvas> 元素 + 加载 css/js
├── style.css      # 深色页面背景、居中画布、标题样式
└── game.js        # 全部游戏逻辑，按职责分区
```

`game.js` 内部按职责分区（~250 行规模，单文件更易维护，长大后再拆）：

1. **配置常量** — 画布尺寸、颜色、重力、跳跃力度、初始/最高速度、障碍物参数
2. **游戏状态** — 当前速度、分数、最高分、`gameOver` 标志、实体（恐龙 + 障碍物数组）
3. **输入处理** — `keydown`/`keyup` 监听空格/↑ 跳、↓ 蹲
4. **物理更新** — 重力、跳跃/下蹲、AABB 碰撞检测
5. **生成逻辑** — 障碍物随机生成与间隔、难度递增
6. **霓虹渲染** — 背景网格、地面、恐龙、障碍物、分数的发光绘制
7. **游戏循环** — `requestAnimationFrame` 驱动：更新 → 碰撞 → 渲染

**数据流**：单循环 `输入 → 更新状态 → 碰撞判定 → 渲染`，每帧重复。

## 5. 核心玩法机制

### 游戏循环
`requestAnimationFrame` 驱动，每帧「更新物理 → 碰撞判定 → 重绘」。约 60fps，参数按帧计算。

### 恐龙物理
- 站在地面；按空格/↑ 获得向上初速度，受重力回落，落地停止
- 按 ↓ 下蹲：恐龙高度变矮（命中框缩小）；空中按 ↓ 加速下落
- 跳跃与下蹲互斥；无二段跳

### 障碍物
- **仙人掌**（地面）→ 跳过去
- **翼龙**（空中，高/低两档）→ 低飞的蹲躲，高飞的可从下方直接跑过

### 计分
按存活距离/时间累加，右上角显示；最高分用 `localStorage` 持久化。

### 难度递增
随分数上升，移动速度缓慢提升、障碍物出现间隔逐渐缩短。

### 死亡与重开
碰撞 → 冻结画面、显示 `GAME OVER` + 当前分/最高分 + 提示「按空格重新开始」；按空格重置并重开。

### 霓虹视觉
- 深蓝黑底色 + 发光水平/垂直网格线（赛博地平线）
- 恐龙、仙人掌、翼龙用 `shadowBlur` 霓虹描边（青色恐龙、品红障碍物）
- 发光地平线；分数用发光等宽字体

## 6. 边界情况与错误处理

- **连续按键跳跃**：`keydown` 用 `event.repeat` 过滤，仅在地面起跳，避免按住空格连跳
- **切标签页/后台**：`requestAnimationFrame` 后台自动暂停，恢复时用 delta time 上限钳制（clamp），防止恢复瞬间"瞬死"
- **窗口失焦丢按键**：监听 `blur` 清空输入状态，避免卡在"下蹲"
- **localStorage 不可用**（隐私模式等）：`try/catch` 包裹，失败则最高分退回内存
- **障碍物密集/重叠**：生成时设最小间隔，避免不可通过的贴太近
- **响应式**：固定逻辑画布尺寸（900×300），CSS 缩放适配窗口，不拉伸变形

## 7. 测试策略

极简 + 无构建环境，以手动验收为主：

- **纯逻辑抽成纯函数**：AABB 碰撞检测、难度曲线计算、障碍物生成间隔——与渲染/输入解耦，便于将来加自动化测试
- **手动验收清单**：
  - [ ] 跳：空格/↑ 起跳，落地后能再跳
  - [ ] 蹲：↓ 变矮，空中 ↓ 加速下落
  - [ ] 仙人掌：跳过不死亡
  - [ ] 翼龙：低飞蹲躲、高飞直接跑过
  - [ ] 死亡重开：碰撞后按空格重开
  - [ ] 最高分持久化：刷新后最高分保留
  - [ ] 后台恢复：切走再切回不瞬死
